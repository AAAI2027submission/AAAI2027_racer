# Four Support Experiments Summary

This folder collects the four experiments shown in `plots/all_support_experiments_bars.png`.

- `all_support_experiments_summary.csv`: combined reward bar data.
- `four_experiments_policy_summary.csv`: selected policy row from each experiment summary.
- `per_experiment/`: copied experiment summaries and seed-level selected-policy results.
- `support_data/`: copied raw `model_informed_offline_support.csv` files.
- `support_edges_by_seed.csv`: support edge totals by experiment and seed.
- `support_edges_summary.csv`: support edge means and SEMs used for the support plot.
- `plots/`: combined reward bar plot and support edge plot.
