# Block Vs Global LR 10-Seed Summary

This folder collects the data shown in `plots/block_vs_global_lr_10seed_error_bars.png`.

- `block_vs_global_lr_10seed_summary.csv`: combined reward bar data.
- `selected_policy_summary.csv`: selected policy rows from each LR-mode summary.
- `selected_policy_seed_results.csv`: seed-level rows for the plotted policies.
- `per_lr_mode/`: copied LR-mode summaries plus split seed-level policy results.
- `support_data/`: copied raw `model_informed_offline_support.csv` files.
- `support_edges_by_seed.csv`: support edge totals by LR mode and seed.
- `support_edges_summary.csv`: support edge means and SEMs used for the support plot.
- `plots/`: combined reward error-bar plot and support edge plot.
