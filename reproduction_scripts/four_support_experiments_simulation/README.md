# Four Support Experiments Simulation

This folder contains the simulation code and run context for the MIT Supercloud
four support-prior experiments summarized in `four_support_experiments_summary`.

## Main Script

Run the simulations with:

```bash
python st_tw_tmtw_comparison/run_eight_dc_exp4_combine_variant_2d_state.py
```

The script writes:

- `combine_variant_2d_state_results.csv`
- `combine_variant_2d_state_round_rewards.csv`
- `combine_variant_2d_state_summary.csv`
- `model_informed_offline_support.csv`
- `run_config.json`

It imports shared RMAB utilities from:

```text
baseline_setting_suite_v1/experiments/run_experiments.py
```

## Gated Offline Prior

```bash
python st_tw_tmtw_comparison/run_eight_dc_exp4_combine_variant_2d_state.py \
  --source-results eight_dc_exp4_combine_variant_2d_state_mit_supercloud_rules_offline_10seed_source.csv \
  --datacenter-dir datasets/mit_gpu_datacenter_with_metrics_calibrated \
  --output eight_dc_exp4_combine_variant_2d_state_mit_supercloud_model_support_variants_10seed_results \
  --rounds 1500 \
  --queue-states 40 \
  --exclude-tm-tw-family \
  --policy-labels oracle,tw_gated_offline,tw_gated_offline_low_rank,tw_support_offline \
  --low-rank-max-rank 10 \
  --block-low-rank
```

## Included Context

- `eight_dc_exp4_combine_variant_2d_state_mit_supercloud_rules_offline_10seed_source.csv`: source seeds/settings.
- `configs/gated_offline_prior_run_config.json`: saved config for the model-informed support variants run.
- `configs/gated_offline_block_lr_run_config.json`: same saved config, used for the block-LR row subset.
- `configs/rule_based_support_run_config.json`: saved config for rule-based support.
- `configs/model_rules_union_run_config.json`: saved config for model-informed union rule-based support.

The commands above expect `datasets/mit_gpu_datacenter_with_metrics_calibrated`
to exist at the repository root.
